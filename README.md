# Fura — Utanumhald

Vefsvæði sem flokkar Yfirlit-skrár úr vigtunarkerfinu í mánaðarsamantekt (xlsx).

Þrír flipar: **Hjólbarðar · Timbur · Málmar** — hver með sínu mapping, þröskuldi og útgangsstíl sem matchar `Hjólbarðar 2026.xlsx`, `Hreint timbur 2026.xlsx`, og `Samantekt járns 2026.xlsx`.

## Hvernig það virkar

1. Dragðu Yfirlit (xlsx) inn.
2. Vélin flokkar sjálfvirkt og spyr þig um það sem er óljóst:
   - Vafasamar stórar færslur (líklega villur)
   - Nýir viðskiptavinir ≥ þröskuldi (eigin bakki eða Einka?)
   - Nýjar efnislýsingar (hvar á að fara?)
3. Þú svarar í spjalli → vélin uppfærir flokkunina.
4. Hlaðið niður xlsx — tilbúið til notkunar.

## Keyra lókalt

Opnaðu `index.html` í vafra (Chrome / Edge / Safari).
